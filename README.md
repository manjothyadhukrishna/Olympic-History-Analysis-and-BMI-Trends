# Olympic-History-Analysis-and-BMI-Trends
This project exploring Olympic Games history, medal distributions, and athlete BMI trends from 1896 to 2016. Designed to visualize country 
performances and physiological trends among athletes over the decades

Key Features

Historical medal tallies for top countries.
  
Breakdown of medals by sports events and seasons.
  
Athlete BMI trends and weight classifications (Normal, Overweight, Obesity, Underweight) from 1900 to 2016.
